# Handoff: JAMbo, Swift-версия — следующий этап: мануал по приложению и упрощённая версия

## 1. Контекст
Groovebox для iPad. Веб (`src/`, `public/`, ветка main) — эталон, заморожен. Swift-версия — ветка `swift`, `ios/JAMbo.swiftpm` (Swift Playgrounds). Правила — `CLAUDE.md`, `ios/CLAUDE.md`; вехи — `docs/SWIFT_AUDIT.md` (раздел 6), итоги — `docs/SWIFT_MILESTONE_Sx.md`; поведение по темам — `docs/ai/*.md` (в ветке swift описывают Swift-версию).
