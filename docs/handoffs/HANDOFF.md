# Handoff: JAMbo, Swift-версия — следующая сессия: публикация мануала и облегчение сборки

## 1. Контекст
Groovebox для iPad. Веб (`src/`, `public/`, ветка main) — эталон, заморожен. Swift-версия — ветка `swift`, `ios/JAMbo.swiftpm` (Swift Playgrounds). Правила — `CLAUDE.md`, `ios/CLAUDE.md`; вехи — `docs/SWIFT_AUDIT.md` (раздел 6), итоги — `docs/SWIFT_MILESTONE_Sx.md`; поведение по темам — `docs/ai/*.md` (в ветке swift описывают Swift-версию).

## 2. Состояние (17.11)

## 3. Сделано 17.11
- Нагрузка интерфейса: общие часы анимаций FrameClock / FrameTimeline (60 / 30 / 10 Гц), измеритель спит в тишине, узкие наблюдаемые значения хода игры (SWIFT_MILESTONE_S14.md «Нагрузка интерфейса»).
- UNDO / REDO переключают на место правки (дорожка, клип, страница, окно; AppModelUndoPlace.swift).
- DRUM STEP PAINT (SETTINGS → RECORD): рисование тригов пальцем на ударных и сэмплах.
- MULTICORE (SETTINGS → AUDIO ENGINE, по умолчанию ON): RenderPool (Core/Engine), помощники в аудио-группе выхода (Audio/AudioWorkgroup.swift; os_workgroup через dlsym — в Swift API закрыт). Задания: дорожки синта, эффекты дорожек, EQ дорожек, которые не слушают другие. Строка Load под рычажком — нагрузка по разделам. iPad, 16 дорожек: CPU 90 → 48–55 %.
- Эффекты на каждой дорожке: свои Reverb, Delay, Drive, хранятся в клипах дорожки (Clip.fx), Duck общий, посылы параллельные; версия проекта 10 (старым — прежние общие FX всем клипам). MORPH на FX — исходное, точка, возврат RETURN; SHIFT + MORPH — все дорожки; при SHIFT + MORPH кнопки FX и MOD переключают страницу (toggle — только SHIFT + тап без MORPH).
- Подробно — docs/ai/fx-eq.md, docs/ai/settings-midi-sync.md, SWIFT_MILESTONE_S14.md («Многоядерный режим», «Эффекты дорожек»).
