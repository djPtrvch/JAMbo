# Иконки движков (стиль Ink)

Правила
- ОДИН ЦВЕТ: все иконки рисуются currentColor (чёрные на светлой теме, белые на тёмной). Никакой оранжевой подсветки параметра, пунктирных «призраков» и цветных точек. Изменения видны только по форме. Цвет берётся от color родителя / CSS-переменной темы.
- Линия 1.8 px на сетке 64×64, без заливок (кроме точек). Базовая иконка белая; то, что двигает ручка, оранжевое (как значение); остальное серое. Жёлтый только для выбора (рамка дорожки, выбранный дискретный пункт при p-lock).
- Иконка живая: перерисовывается при вращении Harmonics/Timbre/Morph (колонка 1, ручки 1.1–1.3), в том числе по LFO и p-lock.
- Дискретные параметры (банк вейвтейбла, тип аккорда, режим речи) показываются выбором пункта, а не плавным морфом.
- Код: engine_icons.js, ICONS[id]({h,t,m}) возвращает элементы (путь или круг) с пометкой, от каких параметров они зависят.

Что меняется (H / T / M)
0 Classic waves: ghost-пила уезжает по фазе / ширина импульса квадрата / пила: треугольник→пила
1 Waveshaper: кривая от линейной к насыщенной / глубина фолда (больше изломов) / смещение формы по вертикали
2 FM: частота модулятора в форме волны / плотность и «рваность» формы / дуга обратной связи вокруг оператора растёт
3 Granular formant: вторая метка на спектре едет / частота внутри зерна / ширина огибающей зерна
4 Harmonic: число горбов (1–4) / положение главного горба / горб: широкий→узкий
5 Wavetable: банк A–D (4 квадрата) / выбранная строка стопки / вертикальный курсор (столбец)
6 Chords: точки по интервалам аккорда (11 типов) / обращение (нижние ноты уходят вверх) / справа форма волны, от синуса к богатой
7 Speech: 4 точки режима (formant/SAM/LPC/words) / расстояние между глазами («существо») / форма рта (oo→ah→ee)
8 Granular cloud: вертикальный разброс кружков / их число / их радиус (перекрытие)
9 Filtered noise: кривая фильтра LP→BP→HP / крупность ступенек шума / пик резонанса
10 Particle noise: разброс точек по сетке / число точек / круги (all-pass) → вертикальные полосы
11 String: частичные уходят от гармоник / острее щипок / дольше затухание (описание движка не найдено в источнике, проверить)
12 Modal: кольца: равные→неравные промежутки / лучи удара (число) / кольца гаснут медленнее
13 Bass drum: перегруз (срезанные вершины) / третья гармоника / длина затухания
14 Snare: шум vs тон / вторая мода / затухание
15 Hi-hat: ровные тики vs рваные / линия среза HPF едет вверх / затухание
Sampler: частота волны внутри региона / маркер start / маркер end

## AUX / OUT (только струна 11, modal 12, kick 13, snare 14, hi-hat 15)
Источник: мануал Plaits. У этих пяти движков третья ручка (вместо Morph) = OUT→AUX, затухание идёт от ручки Decay (v.d).
- Параметры иконки: v.h (Harmonics), v.t (Timbre), v.m (0 = OUT … 1 = AUX, плавный кроссфейд), v.d (Decay, по умолчанию 0.5). Точки больше нет: меняется сама форма.
- 11 String (Harmonics = материал/негармоничность, Timbre = яркость возбуждения): OUT затухающая волна струны → AUX сырой возбудитель, короткий шумовой всплеск без резонанса. Материал на AUX не виден, яркость задаёт гладкость шума. В источнике у струны описание общее с modal.
- 12 Modal: OUT кольца резонатора (материал = расстояния, Decay = как долго светятся) → AUX сырое возбуждение: кольца гаснут, вырастают лучи удара и «пыль».
- 13 Kick: OUT щелчок, падающий по высоте синус и перегруз (T-сеть) → AUX FM-треугольник, превращённый диодами в синус: округлая волна, глубже падение, мягкий VCA. Разница тонкая.
- 14 Snare: OUT три затухающих моды корпуса + сглаженный BP-шум → AUX пара FM-синусов + острый HP-шум.
- 15 Hi-hat: OUT шесть квадратов, тики разбросаны, «грязный» VCA → AUX три пары кольцо-модуляции: тики собираются в три кластера, на вершинах квадраты, чистый VCA.
- Остальные движки AUX не показывают (Morph работает как обычно).

## Перерисовано (v2)
- 0 VA: квадрат сверху (Timbre = ширина), пила снизу (Morph), пунктирные направляющие по периоду квадрата; детюн (Harmonics) сдвигает период пилы относительно направляющих.
- 6 Chords: точки нот (тип аккорда и обращение меняют их положение) + текстовая метка типа (oct, 5, sus4, m, m7, m9, m11, 6/9, M9, M7, M) + справа мини-волна (Morph).
- 10 Particle: частицы-точки (Timbre = число, Harmonics = разброс); Morph: <50% у каждой частицы кольца-«ревербератор» (all-pass), >50% хвост-звон (полосовой).
- 15 Hi-hat: два тарелки на стойке; Decay раздвигает тарелки (открытый хэт); Timbre/HPF = число и длина лучей (больше лучей короче); Harmonics = лучи сплошные (металл) → рваные (шум); AUX = лучи собираются в три пары (кольцо-модуляция).
