# Движки синта

Часть спецификации поведения, вынесенная из CLAUDE.md. В ветке `swift` файл описывает Swift-версию (прежнее поведение веба — в ветке main); DSP своих движков — Core/Jambo, по образцу worklet веба. Ссылки «см. „Раздел“» ведут в другие файлы docs/ai/ — по таблице в CLAUDE.md.

## Движки и иконки
- Таблица движков — одно место для названий, подписей ручек 1.1–1.4 и их типа (плавная или ступенчатая). Подписи в интерфейсе — на английском:

| id | Движок | 1.1 | 1.2 | 1.3 | 1.4 |
|---|---|---|---|---|---|
| 16 | KICK (свой, бочка) | pitch (30–100 Hz) | sweep | drive | click |
| 17 | ANALOG (свой) | wave A (ступенчатая, 4: Sine, Triangle, Saw, Square) | wave B (ступенчатая, 4) | detune | mix |
| 18 | FM (свой) | ratio (×2.00) | index | contour | feedback |
| 19 | WTABLE (свой) | position | warp | unison (ступенчатая, 3: 1, 3, 5) | detune |
| 20 | SNARE (свой) | tune (120–400 Hz) | snappy | tone (0.8–8 kHz) | punch |
| 21 | HAT (свой) | tune (±1 oct) | spread | tone (×0.5…×2) | noise |
| 22 | CLAP (свой) | tone (700–3000 Hz) | bursts (ступенчатая, 6: 1–6) | spread (2–25 ms) | tail |
| 23 | PERC (свой) | tune (60 Hz–2 kHz) | material | bend | hit |
| — | Sample | pitch | start | end | — |

- Движков Mutable Instruments (Plaits, id 0–15) нет. Звук с ключом mi:0…mi:15 загружается пустым: у дорожки — без звука (как новая дорожка), её ручки остаются; пресет-лок шага с таким звуком снимается (шаг играет звук дорожки); пресет в папке дорожки или библиотеке — пустой (при выборе дорожка без звука). Номера своих движков (16–19) и ключи mi:<n> не меняются.
- Иконка движка: генератор из docs/icons/engine_icons.js, перенесён в src/engineIcons.ts (логика форм та же; как должно выглядеть — docs/icons/engines-1..3.png и engines-4-aux.png, перерисованные VA, Chords, Particle и Hi-hat — redo-dark.png и redo-light.png, что меняется у каждого движка — docs/icons/ENGINE_ICONS_SPEC.md). Параметры 0…1: h — ручка 1.1, t — 1.2, m — 1.3, q — 1.4, d — Decay 2.2 (по умолчанию 0.5). У Sample — волна с маркерами start и end. У KICK (16) — затухающая волна: частота по PITCH, в начале выше на SWEEP, насыщение по DRIVE, длина затухания по Decay, в самом начале — вертикальная полоса клика, высота по CLICK. У ANALOG (17) — две волны: сверху A (пункт WAVE A), снизу B (пункт WAVE B), B расходится по фазе с DETUNE; прозрачность A и B — по MIX. У FM (18) — сверху модулятор (частота по RATIO, полупрозрачный), ниже несущая с фазовой модуляцией: глубина по INDEX, спадает вдоль иконки по CONTOUR и Decay; в углу — отношение (×2, ×1.5). У WTABLE вместо иконки — кадр таблицы.
- Иконка живая: перерисовывается (requestAnimationFrame) при любом изменении ручки, в том числе от LFO/ENV и p-lock (с зажатым шагом — его значения). У ступенчатых ручек (1.1 ANALOG) иконка переключается скачком по пункту.
- Цвет из CSS-переменной темы, всегда один: белая в тёмной теме, чёрная в светлой (подсветки частей нет); сетка 64×64, линия 1.4 (в источнике 1.8 — в приложении чуть тоньше). Жёлтый — только рамка выбранной дорожки. Отдельных индикаторов (точки AUX, «призрака» положения) нет: AUX виден по самой иконке.
- Где: только в окне сэмпла слева, у синта — крупная иконка (до 120 px, в невысоком окне Safari ужимается, чтобы текст под ней не наезжал) над именем движка; на дорожках иконок нет (рамка выбранной дорожки жёлтая). Тап по иконке (как по всему окну) открывает меню звука (две колонки: слева DRUMS — KICK, SNARE, HAT, CLAP, PERC; справа SYNTH — ANALOG, FM, WTABLE, под ними SAMPLER; ниже LOAD), выбор меняет движок дорожки, подписи и типы ручек 1.1–1.3 (подпись под ручкой). У сэмпла в окне остаётся его настоящая форма волны. Пока зажат шаг со своим звуком, иконка показывает звук шага.
- Ступенчатая 1.1 хранит значение в процентах, как прежде, и встаёт на середину пункта (у ANALOG — Sine, Triangle, Saw, Square).

## Свои движки JAMbo
Четыре своих синт-движка: KICK, ANALOG, FM, WTABLE (номера 16–19, family: 'jambo'). Ключ звука — 'mi:<n>'. Иконки: KICK, ANALOG, FM — живые (см. «Движки и иконки»), у WTABLE — кадр таблицы.
- Архитектура: AudioWorklet public/jambo-synth-worklet.js (чистый JS, без WASM), протокол как у plaits-worklet.js: узел на дорожку, 6 моно-выходов (по голосу), дальше те же цепочки голосов (огибающая Attack/Decay, Level, фильтр, Pan, посылы). Сообщения: note { slot, frame, end, engine, note, p1, p2, p3, decay, accent }, mod { slot, note, p1, p2, p3, decay }, stop { slot, frame }, table { frames, levels }; узел раз в ~0,5 с присылает cpu. p1–p3 — ручки 1.1–1.3 (harm, timbre, morph) 0..1, decay — ручка Decay в мс. На дорожке — по узлу каждого нужного семейства (создаётся при выборе движка), оба подключены к одним цепочкам голосов: смена семейства (движок дорожки или звук шага) ничего не пересоздаёт; если слот занимал голос другого семейства, тот глушится сообщением stop в кадре новой ноты (огибающая уже погашена) — без щелчка. Нагрузка обоих узлов — в индикаторе CPU.
- Общее DSP: высота — MIDI-нота (69 = A4 = 440 Гц, как у Plaits), частота — sampleRate узла; фаза новой ноты у ANALOG, FM и WTABLE (центр) — как у генератора, который бежит непрерывно (frac(f·t), у ANALOG — по времени с дрейфом; оба осциллятора ANALOG — из одной точки): ноты одной высоты встают в фазу с хвостом прошлой и не гасят его (при случайной фазе уровень прыгал от ноты к ноте — синус звучал прерывисто); смена ручек на лету сглаживается (~5 мс); в process() нет выделений памяти (буферы Float32Array заранее), состояния фильтров обнуляются у денормалей; пик ≤ 0 dBFS при Level по умолчанию.
- KICK (в меню — KICK, ключ звука прежний, mi:16) — синтезатор бочки (decay: true — затухает сам, огибающая дорожки только с атакой, как STRING и MODAL): синус с экспоненциальной огибающей высоты + клик (2 мс) → мягкий клиппер; шума нет. Монофонична: удары дорожки идут в один голос (слот 0), новый удар обрывает прошлый — хвост гаснет за ~2 мс до клиппера (без щелчка и без перегруза от наложения хвостов); из аккорда звучит одна нота. Высота — ручкой PITCH, нота её не меняет. 1.1 PITCH — 30 → 100 Гц логарифмически, по умолчанию (середина ручки) ≈ 55 Гц; на ручке «55 Hz». 1.2 SWEEP — свип 0 → +48 полутонов над PITCH, время свипа = clamp(0.08 × Decay, 6, 80 мс); 0 % — ровный тон, 100 % — панч и «зап». 1.3 DRIVE — только насыщение: tanh (запас 1 → 12) с компенсацией громкости. 1.4 CLICK — громкость и яркость атаки: уровень клика 0 → 1.0 и длина 3 → 1 мс (50 % — 2 мс, как прежде); перевод старых проектов — CLICK = прежний DRIVE (уровень клика тот же, длина отличается от прежней не больше чем на 1 мс). Decay — время затухания до −60 dB (постоянная экспоненты = Decay / 6.9), у KICK ручка Decay — 0…1000 мс (своя шкала, значение по умолчанию 500 мс; при переключении на KICK большее значение подрезается до 1000 мс, вместе со сменой движка — одна запись в UNDO; движок тоже ограничивает 1000 мс — на случай LFO/ENV); голос затих — уровень < 1e-5 дольше 4800 кадров; при ударе фаза синуса = 0. Атака дорожки длиннее 2,5 мс начинает удар с нуля.
- ANALOG (обычная огибающая Attack/Decay; при выборе движка на дорожку с другого звука WAVE A и WAVE B ставятся на Sine, DETUNE — на 0 %, MIX — на 50 % (чистый синус), вместе со сменой движка одна запись в UNDO): два осциллятора PolyBLEP, A и B, каждый своей формы, + дрейф (медленное блуждание ±3 цента, общее на дорожку — для всех голосов и осцилляторов); суба и SYNC нет (суб — в движке SUB); фильтр — общий (Filter/Reso). Считается с передискретизацией ×2 и полуполосным фильтром (как FM). 1.1 WAVE A и 1.2 WAVE B — ступенчатые, 4 пункта: Sine, Triangle, Saw, Square (форма — по пункту, без промежуточных смесей; смена пункта на звучащей ноте — кроссфейд прежней и новой формы за 5 мс, без щелчка); формы совмещены по фазе (все положительны на первой половине периода: треугольник с пиком на четверти, пила нисходящая), пик каждой формы выровнен (заранее посчитан по сетке) — уровень не прыгает при переключении; треугольник — интеграл PolyBLEP-квадрата, пила и квадрат — PolyBLEP, квадрат 50 %. 1.3 DETUNE — A вверх, B вниз, в сумме 0 → 60 центов по кривой x². 1.4 MIX — кроссфейд A ↔ B: доли по постоянной мощности (cos/sin), нормированные на их сумму — пик не растёт, при 50 % и одинаковых формах звук прежний. Перевод старых проектов: A и B — прежний WAVE, DETUNE — прежний, MIX 50 %; у дорожек, где был SUB > 0, суб пропадает — при открытии проекта сообщение со списком таких дорожек («SUB removed (ANALOG): T2, T5»).
- FM (обычная огибающая): несущая (ratio 1) + модулятор (RATIO), фазовая модуляция с самомодуляцией модулятора; передискретизация ×2 с полуполосным фильтром децимации (63 отвода, окно Блэкмана–Харриса), синус — таблица 4096 точек с линейной интерполяцией. 1.1 RATIO — 0.5 → 8 логарифмически, с привязкой (±2 %) к 0.5, 1, 1.5, 2, 3, 4, 5, 6, 7, 8; на ручке «×2.00». 1.2 INDEX — 0 → 10 рад по кривой x^1.5; обратная связь = 0.35 × нормированный индекс × (FEEDBACK / 50 %) (в долях периода). 1.3 CONTOUR — огибающая индекса от Decay: 0 % постоянный (орган, бас), 50 % спадает вместе с амплитудой (постоянная Decay / 4), 100 % — в 5 раз быстрее (щипок, колокол). 1.4 FEEDBACK — 0…100 %, по умолчанию 50 % (звук как прежде).
- WTABLE (обычная огибающая): чтение кадров таблицы с линейной интерполяцией по фазе и между кадрами; мипмапы по октавам (уровень L — гармоники до 1024 >> L; строятся обратным FFT с обрезкой гармоник в основном потоке, src/audio/wavetable.ts, и передаются в узел). 1.1 POSITION — кадр 0 … N−1 с интерполяцией. 1.2 WARP — 0–50 % изгиб фазы φ^(1+3w), 50–100 % к изгибу добавляется синхронизация 1 → 4. 1.3 UNISON — ступенчатая, 1 / 3 / 5 голосов; 1.4 DETUNE — 0 → 60 центов: при 3 голосах боковые на ±DETUNE, при 5 — на ±DETUNE и ±DETUNE/2; боковые на −3 дБ, со случайной фазой; громкость нормируется по числу голосов; движок моно. Перевод старых проектов: UNISON ≤ 25 % → 1 голос, выше → 3 голоса, DETUNE — прежняя расстройка (0…40 центов).
  - Встроенные таблицы (генерируются в коде, 64 кадра × 2048, каждый кадр к пику 1.0): BASIC (синус → пила → квадрат, по умолчанию), PWM, ORGAN (дроубары), FORMANT (гласные A, E, I, O, U аддитивно), DIGITAL (наборы гармоник), METAL (инхармонические партиалы). Сторонних таблиц в репозитории нет.
  - Свои таблицы: WAV (PCM 16/24 бит или float 32; моно, у стерео — левый канал; до 4 МБ, до 256 кадров). Размер кадра — из чанка 'clm ' (метка Serum), иначе выбор при импорте: AUTO (по длине файла; 2048, если длина делится) или 256 / 512 / 1024 / 2048 (с числом кадров). Байты — в хранилище сэмплов (ключ по содержимому), в библиотеке — узел kind: 'table' (ключ таблицы 'wt:<ключ сэмпла>:<размер кадра>'). Своя таблица нормируется целиком к пику 1.0.
  - Браузер, режим LOAD TABLE (кнопка TABLE в меню звука у дорожки с WTABLE): только папки и таблицы (▦, у своих — размер кадра); в корне — папка BUILT-IN TABLES (встроенные, не удаляются); IMPORT читает WAV как таблицы; тап по таблице ставит её на дорожку (отмена — UNDO). В обычном режиме браузера таблиц не видно. EXPORT таблицы — исходный WAV (в .zip папки — тоже).
  - Таблица — у дорожки (doc.tracks[i].table, '' — BASIC): сохраняется в проекте (байты своих таблиц — в .jambo при EXPORT, как сэмплы) и в пресете синта (поле table).
  - В окне синта вместо иконки — текущий кадр таблицы с учётом POSITION и WARP (с LFO/ENV и p-lock, в реальном времени), под ним — имя таблицы.

## Ударные JAMbo
- Общее: SNARE, HAT, CLAP, PERC (номера 20–23, family 'jambo'), как KICK — затухают сами (огибающая дорожки только с атакой), монофоничны (удары — в слот 0, новый обрывает прошлый за ~2 мс; из аккорда — одна нота), высота — ручками, нота её не меняет. Decay (2.2) — длина звука, своя шкала: SNARE 30–800, HAT 20–1500, CLAP (хвост) 50–1200, PERC 30–2000 мс (большее значение при выборе движка подрезается, как у KICK; меньшее — внутри движка). Фильтр, огибающая и посылы — общие колонки 2–3. Числа — ориентиры, итог — на слух.
- SNARE: корпус — два синуса (f и 1.8·f) с экспоненциальным затуханием + шумовые «струны» (белый шум → полосовой). 1.1 TUNE — f 120 → 400 Гц логарифмически. 1.2 SNAPPY — баланс корпус ↔ шум (постоянная мощность). 1.3 TONE — центр фильтра шума 0.8 → 8 кГц логарифмически. 1.4 PUNCH — падение высоты корпуса от +0…+12 полутонов за 10–30 мс и щелчок в начале.
- HAT (схема 808): шесть квадратных осцилляторов 205.3 / 304.4 / 369.6 / 522.7 / 540 / 800 Гц → два полосовых (≈3.4 и 7.1 кГц) → ФВЧ; PolyBLEP, ×2 передискретизация. 1.1 TUNE — весь ряд ±1 октава. 1.2 SPREAD — разнос частот: ниже 50 % ряд сжимается к среднему тону, 50 % — 808, выше — шире (показатель степени отношений 0…2). 1.3 TONE — сдвиг полосовых ×0.5…×2. 1.4 NOISE — металл ↔ белый шум (постоянная мощность). Closed / open — только Decay.
- CLAP: белый шум → полосовой Q≈2. 1.1 TONE — 700 → 3000 Гц (кривая: на 50 % ≈ 1.1 кГц). 1.2 BURSTS — 1–6 вспышек (по умолчанию 4). 1.3 SPREAD — интервал между вспышками 2 → 25 мс (на 50 % ≈ 11 мс); выше 60 % — случайный разброс интервалов (до ±40 %). 1.4 TAIL — уровень хвоста-«комнаты» против кластера; длина хвоста — Decay.
- PERC: шесть затухающих синусов + шумовой толчок. 1.1 TUNE — основная мода 60 Гц → 2 кГц логарифмически. 1.2 MATERIAL — набор мод от кожи через дерево к металлу (плавно между соседними наборами): мембрана 1 / 1.59 / 2.14 / 2.30 / 2.65 / 2.92, брусок 1 / 2.76 / 5.40 / 8.93 (+ 13.34, 18.64), металл — как коровий колокол 808 (540 и 800 Гц и их нечётные гармоники); у более высоких мод затухание короче. 1.3 BEND — падение высоты в начале: 0 — ровно (клавес, блок), 100 % — +12 полутонов за ~60 мс (том, конга). 1.4 HIT — колотушка: мягкая (длинный тёмный толчок) ↔ палка (короткий яркий толчок и щелчок).
- Иконки (живые, по правилам ENGINE_ICONS_SPEC): SNARE — затухающая волна корпуса (частота по TUNE, начало выше на PUNCH) и над ней шумовая полоса (размах — SNAPPY, мелкость — TONE), длина — по Decay; HAT — шесть вертикальных линий (частоты ряда: положение — TUNE и SPREAD), под ними горб полосового фильтра (по TONE), при NOISE линии рвутся в шум, длина хвоста — Decay; CLAP — вспышки-пики (число — BURSTS, промежутки — SPREAD, выше 60 % — неровные; ширина — по TONE), за ними затухающий хвост (высота — TAIL, длина — Decay); PERC — затухающая волна (частота — TUNE, в начале выше на BEND), справа — линии мод (расстановка — MATERIAL), в самом начале — полоса удара (высота — HIT).
- Проверка (Swift): NaN нет, пик ≤ 0 dBFS при значениях по умолчанию и на сетке ручек; алиасинг HAT по FFT; щелчков вне начала удара нет; нагрузка 8 ударов подряд. Результаты (CoreTests DrumEngineTests, отладочная сборка на виртуалке разработки): сетка ручек 0/50/100 % и Decay 10…2000 мс — NaN нет, пик < 0 dBFS (выход через tanh); по умолчанию SNARE −1.4, HAT −4.1, CLAP −1.8, PERC −0.9 dBFS; через Decay уровень ниже −50 dB; новый удар — стык без щелчка (SNARE, PERC); CLAP — число вспышек по BURSTS; HAT (металл) — посторонние составляющие −53.6 dB (20 Гц–20 кГц, окно Блэкмана–Харриса); 8 ударов по 1 с — SNARE ~5, HAT ~17, CLAP ~7, PERC ~8 % одного ядра.

- Версия формата 4 (S12, этап 2; SynthMigration.swift): ручки своих движков переводятся под 1.4 — у дорожек и звуков перехода MIX, в p-lock шагов (по движку шага или дорожки), в назначениях LFO/ENV (ANALOG: DETUNE с 1.2 на 1.3, SUB снимается; WTABLE: UNISON → DETUNE; KICK: DRIVE ещё и на CLICK) и в пресетах (fmt < 3 → 3: папки, библиотека, .jambopreset). SELF-TEST сверяет с эталонами веба случаи, где звук прежний (ручки случая переведены так же).
- Проверка: node scripts/synth-check.mjs — офлайн-рендер worklet в Node и FFT.
