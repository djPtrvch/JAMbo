# Звук, редактор сэмпла, библиотека

Часть спецификации поведения, вынесенная из CLAUDE.md (веб — эталон). Ссылки «см. „Раздел“» ведут в другие файлы docs/ai/ — по таблице в CLAUDE.md.

## Звук (этап 3)
- Встроенных сэмплов нет: сэмплы загружаются с iPad через окно сэмпла, пока звука нет — дорожка молчит. Высота сэмпла определяется при загрузке только для индикации (YIN; окна — в громкой части звука, не тише 10 % пика, до 1,5 с; короткие удары — окном 1024: у конги, тома нота есть; без ясной высоты — шум, хеты, тарелки — «—»: важна точность, нота не угадывается по спектру — решение пользователя); сэмпл всегда звучит в исходной высоте на C3. Ноты пианоролла и Pitch меняют высоту. Сэмпл — звук дорожки (общий у всех её клипов).
- Голос: сэмпл (Start/End) → Attack/Decay → Velocity → фильтр (LP/HP) с Resonance → Pan → дорожка; посылы Reverb, Delay, Drive идут в общие эффекты FX (шины отдают только обработанный сигнал — сухой звук идёт мимо, количество задаёт посыл дорожки).
- Pitch сэмпла: при SETTINGS → SAMPLER → PITCH = SEMITONES ручка и p-lock встают на целые полутоны, LFO/ENV модулирует плавно; при SMOOTH — плавно.
- RATE сэмпла (ручка 1.4, как в Octatrack): −100…100 %, по умолчанию 100 % (правый край — обычная игра), в центре — стоп, левее центра — реверс (от конца отрезка к началу). P-lock, LFO/ENV и автоматизация — как у других ручек голоса. Два режима — SHIFT + тап по ручке, по умолчанию Pitch; подпись — Rate Pitch / Rate Stretch; режим — у звука дорожки (без p-lock), запоминается вместе со своим значением по умолчанию, двойной тап его не сбрасывает. Rate Pitch: скорость меняет высоту, как на виниле (нота и Pitch — сверху); ниже 5 % звук стихает к нулю. Rate Stretch: таймстретч — высота прежняя (нота и Pitch), сэмпл идёт в темпе проекта и следует за BPM, RATE — множитель скорости (около 0 — звук замирает). Темп файла — по длине: луп в 1, 2, 4… такта 4/4 в 85…170 BPM; у файла от 6 с — ещё и по атакам (совпал с темпом по длине, вдвое больше или меньше, до 2 % — точный по длине, иначе по атакам); короче такта при 170 BPM (1,41 с) — темп не учитывается, скорость только от RATE. Алгоритм — SETTINGS → SAMPLER → STRETCH (общий для проектов, по умолчанию NORMAL; новые ноты — новым алгоритмом): NORMAL — фазовый вокодер (кадры 2048 через 512, фазовая привязка у пиков спектра, общие фазы L/R, сброс фаз на атаке; атаки сэмпла находятся при загрузке — рост энергии больше 9 dB, не чаще раза в 50 мс; куски между атаками тянутся отдельно, на атаке голос начинается заново — удар исходный, без предэха; начало ноты без задержки); BEAT — WSOLA (зёрна 2048 через 1024, поиск стыка ±288 отсчётов, первое зерно без нарастания) — легче, для ударных лупов.
- Длина ноты (удержание): нота секвенсора длиной от 2 шагов держит уровень до своего конца — до самого начала следующего шага, без провала на стыке (Attack → уровень 100 % до конца ноты → Decay как Release); если следующая нота той же высоты продолжает державшуюся (например, нота на весь такт по кругу), прежняя гаснет вместе с атакой новой (постоянная Attack / 3, не меньше 1,5 мс) — без провала и без удвоения уровня; отпущенные раньше хвосты не трогаются; нота в 1 шаг и ratchet — как раньше (Decay сразу после атаки), поэтому прежние паттерны звучат так же. Живая нота с пианоролла держится, пока держат клавишу (отпустили клавишу — её ноты гаснут по Decay; нота с MIDI — один шаг, без удержания). Движки, которые затухают сами (STRING, MODAL, KICK, SNARE, HI-HAT, DRUM), длину ноты не слушают — их физику не трогаем. Сэмпл держится до конца ноты или до своего конца. У синта живая нота получает номер (id), отпускание шлёт в AudioWorklet сообщение end { id, slot, end } — новый конец именно этой ноты (если слот уже занят другой нотой, она не обрывается). ENV в MOD — по длине ноты, как и прежде.
- Duck (прежде Sidechain): триг нот дорожки-источника (FX, SC Source; источник работает и заглушённым; ноты, не прошедшие по Chance, не триггерят; рэтчеты — каждый удар) запускает огибающую в duck-worklet.js; форма возврата — CURVE, глубина — ручка 3.4 Sidechain на дорожке; посылы Reverb, Delay, Drive приглушаются sidechain по переключателям SETTINGS → SIDECHAIN (по умолчанию только Drive); приглушается вход посылов, хвосты эффектов звучат. Подробно — в «FX», колонка 4.
- P-lock и модуляция (LFO, ENV) звучат: значения берутся на шаге, а назначенные LFO/ENV и повороты ручек меняют звучащие ноты в реальном времени (значение уходит в голос, когда изменилось; p-lock шага держит своё).
- Смена звука дорожки (движок, сэмпл, пресет, стрелки, UNDO): ноты, которые ещё держатся (живые и длинные ноты секвенсора), сразу звучат новым звуком — прежний голос гаснет за ~3 мс, пока вступает новый с той же нотой на оставшееся удержание (без sidechain); иначе новый звук был бы слышен только со следующей ноты (у ноты на такт — через 2 с). Свой звук шага не трогается.
- Нажатие ноты в пианоролле сразу играет звук выбранной дорожки (живой наигрыш).
- Дорожка: EQ → громкость микшера → мастер (EQ → сатуратор → компрессор → клиппер → лимитер → громкость выхода). EQ дорожки стоит до эффектов (и до посылов).
- Во всех метрах проекта сигнал от 0 dB (пик ≥ −0.01 dBFS) подсвечивается красным.
- Измеритель уровня справа: выбранная дорожка, при MIX или MST — общий выход мастера после лимитера и громкости выхода (L и R). Серых отметок шкалы на нём нет. Поверх полос — регулятор громкости (белая планка, по той же шкале dB, что и полосы), на всех каналах: у дорожки — её громкость в микшере (та же, что ручка дорожки в MIX: двигаешь одно — меняется другое; −∞…0 dB), при MIX и MST — громкость выхода мастера (стоит после лимитера и ограничивает оконечный сигнал, от 0 dB — по умолчанию, без ослабления — вниз до −∞). Палец вверх-вниз по измерителю двигает его, пока палец на нём — снизу вместо пика его значение (VOL); отмена — UNDO; хранится в проекте и при переходе MIX меняется кроссфейдером плавно. Стерео — две полосы, моно — одна; шкала в dB, пик-холд, метка клиппинга, выше 0 dB — красная полоса; снизу максимальный пик в dB с последнего сброса (тап по числу — сброс), сверху интегральная громкость в LUFS (как в Grand Finale: по BS.1770 — блоки ~400 мс, пороги −70 LUFS и −10 LU; копится с последнего сброса, и пока открыта сетка паттернов). Тап по числу LUFS сбрасывает её — отсчёт заново, сначала значение как у моментальной; при смене канала измерителя (другая дорожка, MIX/MST) сбрасываются и пик, и LUFS.
- Синт: свои движки (KICK, ANALOG, FM, WTABLE; см. synth-engines.md).
- Пресеты синта: движок и Harmonics, Timbre, Morph, Velocity, Attack, Decay, Filter, Resonance (у WTABLE — и таблица). Библиотека пресетов общая для всех дорожек и хранится в браузере (переживает перезагрузку); в папку дорожки пресеты попадают через SAVE и LOAD. Синт — звук дорожки (общий у всех её клипов), p-lock и LFO/ENV на Harmonics, Timbre, Morph звучат.
- Без щелчков: смена TYPE Drive — кроссфейд 20 мс в его worklet; параметры реверба, дилея и Drive сглаживаются в их worklet; у сэмпла край (End или конец файла) гаснет за 4 мс, голос останавливается после 8 постоянных времени Decay (−70 dB), лишний голос (больше 64) гаснет за ~5 мс; у своих движков (ANALOG, FM, WTABLE) новая нота входит плавно за 64 кадра (~1,3 мс) в worklet — иначе скачок волны на старте приходит с задержкой фильтра децимации, когда огибающая уже открыта; у затухающих самих движков с атакой до 2,5 мс огибающая слота на новой ноте не обнуляется (хвост резонатора не обрывается), параметры слота — за ~1 мс. Проверка: scripts/click-check.cjs (запись выхода приложения в Chromium и поиск скачков): все 20 движков, эффекты с синтом и с сэмплом, смена размера Reverb, типа и силы Drive, времени, FILTER и SPREAD Delay, mute — щелчков вне начала нот нет (до исправлений: смена размера Reverb — 31, типа Overdrive — 34, сэмпл с End 70 % — 54, длинный Decay сэмпла — 14, ANALOG с атакой 10 мс — тик на каждой ноте); флаги в начале нот STRING, MODAL, KICK, DRUM — их собственная атака (щипок, удар, клик).
- Запуск с экрана «Домой» (веб-приложение): первые кадры WebKit рисует страницу с неверным масштабом вьюпорта и сам поправляет; пока ширина страницы не совпала с экраном и масштаб не 1, приложение скрыто (виден фон), не дольше 1 с.
- Звук включается первым касанием экрана (ограничение iOS Safari); в Safari вместе с ним запускается беззвучный HTML-аудиоэлемент, чтобы Web Audio не глушился; пока он не включён, в окне сэмпла красная подсказка с его состоянием. Загруженные файлы сохраняются вместе с проектом (этап 4).

## Редактор сэмпла
- Удержание окна сэмпла открывает редактор на месте эквалайзера (от левого края до края миниатюр страниц, справа измеритель уровня; PATTERNS, EQ и редактор не открыты одновременно). Показывает сэмпл выбранной дорожки (у синта, MIX и MST — подсказка).
- Форма волны во всю ширину (стерео — L и R полосами). Два жёлтых маркера обрезки (начало и конец) с ручками внизу: маркер тянут за его ручку (двумя пальцами — оба сразу); отрезаемое затемнено; над пальцем — время маркера. Маркеры обрезки — только выделение для TRIM (ручки Start/End не меняют).
- Масштаб и прокрутка: палец по пустому месту формы волны — вверх-вниз масштаб (вверх — крупнее, точка под пальцем стоит на месте; до 256 отсчётов на окно), влево-вправо — прокрутка; направление фиксируется после первых 10 px. При увеличении в верхней полосе, у её верхнего края, — тонкая полоса прокрутки (видимая часть сэмпла жёлтым). Ложные касания: одиночный тап без движения ничего не делает, второй палец по пустому месту не масштабирует, касание ладонью (пятно больше 60 px) не считается. Масштаб не в проекте (новый сэмпл — весь сэмпл).
- Маркеры нарезки (slice): двойной тап по пустому месту — новый маркер; над формой волны — полоса 40 px (полоса прокрутки и флажки): флажок — пятиугольник острием вниз с нотой маркера внутри (белый, в светлой теме чёрный; пока тянут — жёлтый), от острия вниз — тонкая линия во всю высоту; маркер тянут за флажок (между соседями; над пальцем — нота и время; одна запись в UNDO), двойной тап по флажку — удалить; добавление и удаление — запись в UNDO. Свою ноту маркеру назначают так: удерживают его флажок (не двигая; флажок жёлтый) и тапают клавишу пианоролла (или нота с MIDI) — маркер получает эту ноту (постоянную, от гаммы не зависит; одна запись в UNDO), сразу звучит его кусок; у двух маркеров одной ноты не бывает: нота уже у другого маркера — не назначается (флажок на 0,5 с красный, звучит маркер этой ноты); выбранные ноты пианоролла и запись не меняются; новый маркер получает ноту по порядку. Ноты по порядку (у маркеров без своей ноты; номер маркера слева направо; если нота по порядку уже назначена другому маркеру — следующая свободная) — SETTINGS → SAMPLER → SLICE NOTES: CHROMATIC (по умолчанию: C3, C#3, D3…) или SCALE (ступени выбранной гаммы от корневой ноты в 3-й октаве; гамма или нота сменились — ноты на флажках меняются). Пока у сэмпла есть маркеры, нота маркера (пианоролл, шаги, MIDI) играет сэмпл от этого маркера до следующего (последний — до конца сэмпла) в исходной высоте (Pitch действует), Start и End не действуют; нота без маркера молчит; без маркеров — как прежде. Полоса воспроизведения: пока звучит голос сэмпла (нота пианоролла, шаг, MIDI), в окне сэмпла слева и в редакторе жёлтая линия (2 px) бежит вправо и по мере движения тает — за 1,2 с от начала ноты становится прозрачной (линия ▶ предпрослушки в редакторе — по выделению, не тает) от начала ноты (с маркерами — от маркера нажатой ноты, до следующего), у каждого звучащего голоса своя; позиция — по времени звука с поправкой на задержку выхода, по скорости ноты (модуляция Pitch не учитывается). Маркеры хранятся у дорожки по ключу сэмпла (doc.tracks[i].slices: { at, note? }, прежние — числами, в проекте и .jambo; переезжают с дорожкой и в PREV); у отредактированной копии (TRIM, NORMALIZE, MONO) маркеров нет.
- Вверху (над формой волны): имя, длина (и длина выделения), ST/M; кнопка ▶ (квадратная; прослушать выделение между маркерами — или весь сэмпл — в исходной высоте, сразу в мастер, как предпрослушка в библиотеке; повторный тап — стоп), LOAD (браузер библиотеки) и SAVE (браузер в режиме сохранения: сэмпл в выбранную папку библиотеки; WAV в «Файлы» — EXPORT в браузере) рядом, за ними TRIM (оставить выделенное), NORMALIZE (пик −0.1 dBFS), MONO (среднее L и R; у моно неактивна), CLEAR, квадратная кнопка ✕ — закрыть (отмена — общей кнопкой UNDO в верхней панели).
- REC (в строке вверху, перед ▶; красная точка и красный текст, красная окантовка) — запись сэмпла. Тап — меню RECORD FROM: INPUT — входы звука (микрофон iPad, подключённый аудиоинтерфейс или другое устройство; имена — после разрешения доступа; без эхоподавления, шумоподавления и автоуровня, на выход не идёт), TRACK — любая существующая дорожка (её выход после её обработки и громкости микшера, как стем: посылы Reverb, Delay, Drive общие и в запись дорожки не входят), MASTER — выход мастера после эффектов мастера и громкости выхода. Выбор источника сразу начинает запись: кнопка красная, на ней ■ и время, слева вверху — «REC · источник» и «0:12 / 1:00»; в окне по мере записи рисуется настоящая форма волны (пики по 128 отсчётов; L и R, по ширине — записанное время, не меньше 5 с; красная линия — текущее место); тап по кнопке — стоп; не дольше 60 с (останавливается и при закрытом окне). Записанное (стерео WAV 24 бит, имя «источник чч-мм-сс», микрофон iPad — «MIC») встаёт на выбранную дорожку (одна запись в UNDO): был на дорожке сэмпл — запись встаёт на его место (и в папке дорожки), так повторная запись перезаписывает прежнюю; не было — добавляется в папку; копия — в RECORDINGS библиотеки (папка «проект дд.мм.гггг»); дальше его правят здесь же (маркеры, TRIM, NORMALIZE, MONO). При MIX и MST REC неактивна.
- CLEAR (в строке вверху, перед ✕) — убрать сэмпл с дорожки и из её папки (дорожка без звука; отмена — UNDO; в библиотеке сэмпл остаётся).
- TRIM, NORMALIZE и MONO сразу ставят на дорожку отредактированную копию (WAV 24 бит, хранится с проектом); в папке дорожки она встаёт на место исходного сэмпла (имя и высота те же); UNDO возвращает исходный.

## Библиотека сэмплов и пресетов (браузер)
- Открывается на месте центра экрана (как EQ, справа измеритель уровня) из меню звука (LOAD, SAVE, TABLE) и редактора сэмпла (LOAD, SAVE). Общая для всех проектов, хранится на iPad в браузере (дерево — localStorage, байты сэмплов — IndexedDB по ключу от содержимого). Веб-страница не может держать папку прямо на диске iPad или в iCloud Drive (в Safari нет доступа к файловой системе) — обмен через EXPORT и IMPORT (папкой — одним .zip); в нативном приложении библиотека будет на диске и в iCloud. Пресеты прежней библиотеки при первом запуске переезжают в папку Presets.
- Вверху: ‹ (на уровень выше), путь (LIBRARY / папка / …), NEW FOLDER, IMPORT (из «Файлов» — iPad или iCloud Drive, можно сразу несколько; выбрать можно любой файл, неподходящие пропускаются, в открытую папку: аудио, пресеты .jambopreset и папки архивом .zip — папки и подпапки восстанавливаются; сжатые архивы из «Файлов» тоже), квадратная кнопка ✕ — закрыть. Ниже список: сначала папки (тап — войти; у папки число элементов), потом сэмплы (∿) и пресеты (◆, с движком), по имени. Папки вложенные — в каждой можно создать ещё.
- Предпрослушка: слева у строк сэмплов и пресетов синта — ▶ (без разделительной линии; у папок и таблиц его нет, имя папки — от левого края). Тап по ▶ не загружает звук и не меняет выбор нескольких (отмеченные остаются): сэмпл звучит целиком, в исходной высоте, сразу в мастер (−3 dB; не зависит от ручек, mute и solo дорожки); пресет — одна нота через выбранную дорожку с движком и параметрами пресета, как звук шага (нота — выбранная в пианоролле, иначе C3; на дорожку пресет не ставится). Новая предпрослушка сэмпла обрывает прошлую.
- Свайп влево по строке открывает справа EDIT (переименовать), EXPORT и корзину (удалить; у непустой папки — второй тап по «DELETE?»). EXPORT — окно «Поделиться» → «Сохранить в Файлы» (любая папка на iPad или в iCloud Drive; где окна нет — обычная загрузка): сэмпл — исходным файлом, пресет — .jambopreset, папка — .zip со всем содержимым (подпапки, сэмплы, пресеты, пустые папки). Строка при этом сужается, имя остаётся видно; открыта только одна строка, тап по открытой закрывает её.
- Загрузка: тап (по событию click — в прокручиваемом списке iOS может отменить касание) по сэмплу или пресету ставит его на дорожку, и в папке дорожки остаётся только он (под окном сэмпла — 1 / 1); браузер остаётся открытым — звуки можно пробовать пианороллом; звук дорожки в списке подсвечен голубым, внизу — что и куда загружено. Удержание сэмпла или пресета — выбор нескольких (жёлтая рамка и ✓, тапы добавляют и убирают сэмплы и пресеты): LOAD — в папке дорожки только отмеченные, по порядку списка (первый звучит, остальные — на стрелках под окном сэмпла, у каждой дорожки своя папка), CANCEL — выход из выбора (кнопки LOAD, CANCEL и SAVE HERE полноразмерные, 48 px). Для зажатых шагов (меню звука шагов) сэмпл становится их звуком, пресеты для шагов не загружаются.
- Сохранение: внизу поле NAME и SAVE HERE — в открытую папку. Если в папке уже есть сэмпл или пресет с таким именем — окно «… already exists»: OVERWRITE (заменить его содержимое, имя и место те же), SAVE AS… (поле ввода с другим, свободным именем — «Name 2»; если и оно занято — снова вопрос) и CANCEL.
- Системная папка RECORDINGS (имя — обычным шрифтом и цветом, как у других папок, перед ним маленькая красная точка; не удаляется и не переименовывается) — для стемов дорожек (см. «Дорожки» → «Запись стемов»).
- Таблицы WTABLE (kind: 'table') видны только в режиме LOAD TABLE (см. «Свои движки JAMbo»).
