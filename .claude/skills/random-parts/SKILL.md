## Правила (держать во всех стилях)
- Стиль — один на проект (Track.drumStyle, DrumRhythm.styles). Партии стиля — MelodyRhythm.partStyle: nil — Techno.
- Запись одна: Track.writePart(role, style:) — Techno и стили; новый стиль — данные в таблицах общего генератора, не своя функция.
- Из p-lock — только Level (velocity: % × 1,27; 127 = 100 %). Звук и ручки не трогать (кроме Swing при AUTO SWING; не у PAD и ARP).
- Ноты — в гамме, от октавы клавиатуры дорожки (Track.keyOctave); у сэмпла с нотой — сдвиг −6…+5 (randomRoot).
- Длина ноты — не за конец выбранных страниц, на короткой странице — не за её конец, не больше 32 шагов.
- BASS, KEYS, LEAD House и Breaks — мимо бочки: дорожка KICK (Project.kickGrid), без неё — шаги стиля.
- Гармония: PAD, KEYS, ARP — новая прогрессия, BASS и LEAD — последняя (lastRandomProgression); в ансамбле — одна на всех.
- PAD без CHORD — одна длинная нота (корень). Аккорды — только в режиме CHORD.
- Стираются выбранные страницы; одна запись UNDO; ритм ударных и нарезка не повторяют прошлый рисунок дорожки.

## Как вносить ТЗ
1. Прочитать ТЗ целиком; неясное (веса, «примерно», конфликт с правилами выше) — спросить до кода, вопросы — с вариантами.
2. Данные — строками, не литералами массивов (объём сборки): ритмы ударных — 16 знаков («x» — 1, «1»…«9» — 0,1…0,9, «.» — 0, варианты через пробел, DrumRhythm.pat); таблицы стилей — «ряд:вес[/длины]» через пробел, шаги 1…16 — шестнадцатеричные 0…f (StyleParts.styleTable); прогрессии — ступени 1…7.
3. Общий код — один для всех стилей: стиль меняет только таблицы и номера правил (styleVel, styleCells vary, расположение голосов).
4. Тесты и прогоны — по необходимости, при крупных правках (новый стиль, новая роль, переделка генератора; решение пользователя): тогда тесты на правила ТЗ (сотни прогонов со случайным генератором) — ноты в гамме, шаги 0…15, длины 1…32 и в пределах страниц, мимо бочки, без наложений (бас, лид), шаг 1 — корень (где ТЗ требует), только «level» в p-lock, частоты выбора по весам — с запасом; затем полный прогон `. ios/tools/swift-env.sh && cd ios/CoreTests && swift test`. Мелкие правки (веса, ячейки, velocity) — без новых тестов и полного прогона.
5. docs/ai/sequencer.md — текст на подтверждение пользователя (правило CLAUDE.md), затем коммит.
6. Объём сборки: новый генератор рядом со старым — +14 тыс. инструкций IR (8779c44); прежний генератор убирать в том же коммите. Замер [calibrate] — тоже только при крупной правке (скилл swift-build-size).
7. Архив для iPad — когда версия готова к проверке.

## Что уже ошибались
- Тест частоты выбора с порогом 650 из 1000 мигал (повторные попытки avoid уводят выбор) — снижен до 580.
- Проверка «нет повторов подряд» для табличных прогрессий («2511») ломала тест: проверять только свободные прогрессии.
- Октава клавиатуры не хранилась в проекте — после перезапуска бас уходил в 3-ю октаву (15.11 — Track.keyOctave).
- Варианты стилей по темпу (D&B, R&B) раздували сборку — убраны (15.11): вариантов по темпу не добавлять без решения пользователя.
