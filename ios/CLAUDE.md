# JAMbo для iPad — Swift-версия (Swift Playgrounds)

Нативное приложение, App Project для Swift Playgrounds: `ios/JAMbo.swiftpm`, ветка `swift`. Поведение — как в веб-версии (корневой CLAUDE.md — эталон; веб заморожен, только исправления). Решение пользователя: переносим всё, что сделано в вебе (кроме чисто браузерного). Аудит и план вех — docs/SWIFT_AUDIT.md; что сделано и как устроено — docs/SWIFT_MILESTONE_Sx.md (см. «Где искать»).

## Структура
- `JAMbo.swiftpm/Core/` — DSP и модель, только Foundation и Synchronization (Accelerate — только под `#if canImport(Accelerate)` с обычной реализацией рядом). Util/ (атомарные значения, очереди, CPU), Engine/ (AudioCore — весь звук), Model/ (Params, Project, правки, UNDO), Sequencer/, Sampler/, Synth/, Jambo/, FX/, Mod/, Master/, EQ/, Icons/.
- `JAMbo.swiftpm/Audio/` — AVAudioSession (48 кГц, буфер 256), один AVAudioSourceNode → `AudioCore.render`; хранилище сэмплов.
- `JAMbo.swiftpm/UI/` — SwiftUI. `JAMbo.swiftpm/Resources/` — эталоны самотеста, PrivacyInfo.xcprivacy.
- `CoreTests/` — сборка и тесты Core на Linux и Mac (`Sources/Core` — ссылка на `JAMbo.swiftpm/Core`).
- `tools/` — install-swift-linux.sh, swift-env.sh; генераторы эталонов (jambo, fx, master, eq, icons).

## Проверка
- Облако: `ios/tools/install-swift-linux.sh` (один раз), затем `. ios/tools/swift-env.sh && cd ios/CoreTests && swift test`. UI и Audio на Linux не собираются — их проверяет только сборка на iPad.
- iPad: GitHub → ветка `swift` → Download ZIP (или архив из чата) → «Файлы» → распаковать → `ios/JAMbo.swiftpm` открыть в Swift Playgrounds.
- «Пришли проект» / «пришли файл проекта» — полный zip ветки `swift` (`git archive`, как Download ZIP GitHub) в чат.
- Package.swift — в виде, который создаёт Playgrounds; правится только через Playgrounds. Значок — только `.placeholder(icon: …)`. Устройство: iPadOS 26.6.2, Playgrounds 4.7.

## Правила кода
- Swift 5 (не режим Swift 6), минимальная iPadOS 18. Только Swift и фреймворки Apple: без C/C++/Objective-C целей, сторонних пакетов, unsafeFlags, своих entitlements и ключей Info.plist. Атомарные значения — Synchronization (запасной вариант — os_unfair_lock с tryLock).
- Файл не длиннее ~600 строк; тело View короче ~40 строк.
- Компилятор Playgrounds медленный («unable to type-check in reasonable time»): выражения — по шагам с явными типами, числовые константы — готовым числом, массивы-литералы ≤ ~100 элементов (данные — из Resources).
- Имена своих типов не совпадают с типами SwiftUI и Foundation (Scene, View, Text, Color, Path…): Core и UI — один модуль.
- Колбэк (AudioCore.render и всё, что он зовёт): без выделения памяти, блокировок, ARC-объектов, созданных в колбэке, Objective-C, print и растущих Swift-коллекций; final-классы, UnsafeMutablePointer, @inline(__always) на горячих функциях; денормалы в обратных связях гасить вручную. Каждый новый вызов в колбэке проверять по этому списку.
- Playgrounds собирает отладочную версию (без оптимизации). В горячих циклах DSP: без вызовов функций из других файлов на каждом отсчёте (встраивание — только внутри файла), состояние класса — в локальных переменных на блок, циклы while, без обобщённых преобразований чисел, глобальные константы других файлов — в локальную переменную, enum с raw value не сравнивать в цикле. Проверка — сверка с эталонами.
- UI → аудио: CoreEvent через SPSCQueue и AtomicFloat; аудио → UI: атомарные значения и кольцевые буферы, UI читает по таймеру. Экземпляры движков и буферы создаются вне колбэка.
- DSP — сверка с эталонами веба (по отсчётам ≤ −60 dB или третьоктавные полосы ±0,5 dB), каждый эталон — в SELF-TEST. Эталоны Web Audio (узлы браузера) — настоящий код веба в headless Chromium через протокол отладки (образец — tools/eq/golden.mjs).
- UI: ручки, шаги, сетки, метры, спектры — Canvas; состояние — @Observable; без перерисовки всего экрана каждый кадр. Вид с индексом читает данные с проверкой границ. Общий DragGesture от 0 px на контейнере перехватывает кнопки внутри — кнопки и меню держать вне него. Пока открыто меню поверх поля с жестами, поле касаний не принимает.
- Меню: низ не ниже верха кнопок дорожек; что не помещается — прокрутка пальцем (MenuScroll) с тонкой полосой справа.
- Надписи — на английском, комментарии и документы — по-русски. Окна закрываются квадратным ✕.
- Swift-файлы из bash через heredoc в кавычках ('EOF') — с одинарной обратной косой: `\(x)`.
- Каждая веха — docs/SWIFT_MILESTONE_Sx.md: что сделано, что проверено, что открыто, подробности устройства.

## Решения
- Частота: всё считается на 48 кГц (если устройство даёт другую, приводит системный микшер).
- Движки синта (S12, решения пользователя): движков Mutable Instruments (Plaits) нет — звук mi:0…mi:15 загружается пустым (docs/ai/synth-engines.md); docs/ai в ветке swift описывает Swift-версию (веб — в main).
- FX — 1:1 по worklet’ам веба.
- Мастер (S5a, отличие от веба): упрощён — сатуратор DRIVE, TYPE, TONE, MIX, FOCUS; компрессор THRESHOLD, ATTACK, RELEASE, MAKEUP, RATIO, KNEE, SC HPF, MIX; клиппер INPUT, CEILING, SOFTNESS, BASS; лимитер INPUT, CEILING, LOOKAHEAD, RELEASE. Без BIAS, OUTPUT, RANGE, HOLD, LINK, MIX клиппера, UNITY, AUDIT; SCALE — всегда 48 dB. Убранные параметры — на значениях по умолчанию (звук как в вебе). PRESETS модулей мастера — с S6 (решение пользователя): у каждого модуля свой список, общий для проектов (UserDefaults); SAVE, тап — загрузить (UNDO), свайп влево — карандаш на сером (RENAME) и корзина на красном (DELETE), как в списках iPad; так же — пресеты EQ (S7). Окна (S6, отличия от веба): пауза дисплея везде FREEZE (в вебе у LIM — HOLD); ввод числом — системное окно, как у EQ; у CLIP шкала TRANSFER — та же, что у дисплея LEVEL (0…−48 dB, сетка 6 dB), как у COMP; у CLIP один дисплей — LEVEL с GR (без WAVE и кнопки VIEW); у SAT — TRANSFER и SPECTRUM (без WAVE и BIAS); поля — как в EQ, без жёлтой подсветки полей, линий и ручек; FREEZE — двойной тап по дисплею. Кнопки мастера при MST — по цепочке: COMP, CLIP сверху, SAT, LIM снизу (в вебе CLIP, LIM / SAT, COMP).
- Клипы (S1d, отличие от веба): у каждого клипа свой паттерн; копии независимы. Подробно — SWIFT_MILESTONE_S1.md.
- Секвенсор и пианоролл (перед S4, отличие от веба): точка p-lock на шаге, 16 × N шагов в ряд, копия шага, 1 OCTAVE и др. Подробно — SWIFT_MILESTONE_S1.md.
- EQ (S5b, отличия от веба): тап по имени у EQ дорожки — меню COMPARE (спектр другой дорожки после её EQ, прозрачнее, «vs имя»), у мастера — окно коррекции наушников CORRECT EQ (одна на приложение, в самом конце выхода, мимо экспорта и записи; профили AutoEQ — IMPORT / EXPORT); строка EQ — имя под бутербродом, TYPE с края поля BPM, 9 равных столбцов до правого края; ввод числом — двойным тапом по FREQ, GAIN, Q, THRESHOLD, RANGE (сброса Q двойным тапом нет); у каждой дорожки свой выбор COMPARE; окно DYN перетаскивается за заголовок; в PRESETS — только имена; двойной тап по точке — удалить, вкл./выкл. — ON/OFF в меню удержания; LISTEN — прослушивание полосы (нового в вебе нет). Подробно — SWIFT_MILESTONE_S5.md.
- Звук у клипа и IMPORT (S14x, решения пользователя): Clip.src у любого клипа, второй звук колбэка — у следующего клипа (next, keepAlt); IMPORT в окне LOAD / MIX — строки с тригами в свободные строки после последней заполненной; CROSSFADER OFF — при игре держатся выход, модули мастера и EQ мастера (globalsHold), громкости дорожек — у клипов своего проекта (S14z); autosave — мастер нового проекта, SAVE, SAVE AS, EXPORT — звучащий; ввод числом в окнах мастера и BPM — двойным тапом; ADD TRACK — клип сразу играет; нарезка звучит в гамме своего клипа. S14y: OVERDUB — в меню под CHORD; миниатюры LFO — пока держат MOD; ступенчатые ручки — пункты от начала до конца хода; занятое имя пресета — вопрос OVERWRITE / SAVE AS; WTABLE в окне — по таблице показа (256 кадров); MIDI OFFSET — свайп вбок; VEL в пианоролле — вбок перетаскивание. S14z: голоса не гаснут при перестановке (переезжают) и при MIX (SoundData.rebind); CROSSFADER OFF — держатся ещё громкость выхода, громкость дорожки — у клипа (TrackSound.vol); SHIFT + двойной тап по MORPH — ALL TRACKS (чёрная линия контура); строки IMPORT — именем проекта. Подробно — SWIFT_MILESTONE_S14.md.
- Правки S14za (решения пользователя): Sidechain в подписях — Duck; Dly Spread 2.3, Dly Filter 2.4; SHIFT + тап по Dly Time и Speed LFO — по темпу / свободно; SAVE нового проекта — случайное имя; ALL TRACKS по умолчанию ON (линия в MORPH — пока выключен); свои значения ручек по умолчанию (SHIFT + удержание, двойной тап, SETTINGS → DEFAULTS); иконки движков — сплошные фигуры без столбиков, окна ICONS нет; нота сэмпла — только при ясной высоте (точность важнее). Подробно — SWIFT_MILESTONE_S14.md.
- TEXTURE и GRANULAR (решения пользователя): в колонке SYNTH, SAMPLER — под PERC; монофоничны, выход стерео; ручки при выборе — по ТЗ, своих у движка нет; иконки меняются только от ручек; GRANULAR читает свой сэмпл — SOURCE в меню звука. Подробно — SWIFT_MILESTONE_S12.md.
- Метры и скоп (S5c, отличия от веба): на измерителе справа заглушённая дорожка — серая; кнопки скопа COMP, CLIP, LIM по умолчанию выключены. Подробно — SWIFT_MILESTONE_S5.md.
- Значения по умолчанию (после проверки S5d, отличие от веба): ATTACK компрессора мастера — 30 мс (в вебе 10), Rev Size — 30 % и Rev Decay — 1,5 с (S12; в вебе 50 % и 2 с); эталоны считаются от значений веба. ● MASTER (запись мастера) — под окном при MIX, на месте стрелок папки; окно при MIX — размером с окно дорожки (при MST строки нет — окно индикации выше).
- Dynamic EQ (S7b, отличие от веба): в кольце источников (дорожки слушают друг друга) задержка — один блок (256 отсчётов; в вебе — 128). Подробно — SWIFT_MILESTONE_S7.md.
- Стемы (S11d, решение пользователя): CAF float 32, как сэмплы (в вебе WAV 24 бит); правила начала и конца — в колбэке. Подробно — SWIFT_MILESTONE_S11.md.
- REC (S11e, решения пользователя): после разрешения доступа к микрофону сессия всегда в режиме записи (REC без перерыва звука; оранжевая точка микрофона), в меню — все входы (USB, аудиоинтерфейс); вход пишется отдельным AVAudioEngine; запись — CAF float 32; кнопки редактора — равной ширины от левого края SCALE верхней панели, ▶ — без жёлтой подсветки. Доступ — Capabilities → Microphone в Playgrounds. Подробно — SWIFT_MILESTONE_S11.md.
- Фон: BACKGROUND AUDIO (SETTINGS → AUDIO ENGINE, по умолчанию ON) — ключ UIBackgroundModes: audio в Info.plist рядом с Package.swift (additionalInfoPlistContentFilePath — исключение из правила «без ключей Info.plist», решение пользователя; Playgrounds может убрать строку при правке манифеста — проверять).
- Свайп влево в списках (решение пользователя, S9): везде одно меню — карандаш на сером (RENAME) и корзина на красном (DELETE), как в пресетах модулей мастера (в вебе у проектов и библиотеки — EDIT и корзина).
- SETTINGS (S9, решения пользователя): вкладки RECORD, SAMPLER, DUCK / MIX, MORPH, LEVEL / AUDIO ENGINE, OUTPUT, APPEARANCE / DEFAULTS (S14za; при запуске — RECORD; APPEARANCE — вкладка). LEVEL: ABSOLUTE — регулятор справа у дорожки и громкость MIX совпадают (звучит ровно громкость MIX); RELATIVE — подстройка Track.trim вниз от громкости MIX (регулятор на итоговой громкости, выше MIX не поднимается, следует за ней; итог vol + trim, и к p-lock громкости MIX); trim хранится в проекте и действует только при RELATIVE. MORPH: ALL TRACKS — ручка меняет тот же параметр на всех дорожках, где он есть на сетке (сдвиг на ту же долю хода от значения при включении режима); RETURN — OFF, 1/4, 1/2, 1 BAR, 2 BARS (плавный возврат по темпу, одна запись UNDO; включили MORPH во время возврата — ручки остаются). MIX (S10): CHANGE KEY — ON: гамма и нота нового проекта (при запуске его клипов, как в вебе), OFF: гамма и нота старого держатся, пока идёт игра (в проект не пишутся); по умолчанию ON. CROSSFADER — ON (по умолчанию): кроссфейдер ведёт общие настройки; OFF: кроссфейдера нет; темп, громкость выхода, модули мастера и EQ мастера старого держатся, пока идёт игра, громкость дорожки — у клипа своего проекта (S14z; темп в проект не пишется). MUTE TAILS — во вкладке DUCK (в вебе — в AUDIO ENGINE; там теперь только «Now:»). В PROJECTS нет RENAME — переименование карандашом. Бутерброд закрывается тапом мимо меню. Выбранная дорожка — жёлтая рамка всегда, и у заглушённой (mute — красная M; в вебе рамка mute перекрывает выбор). Имена дорожек, MIX и MST: выбранная — heavy, остальные — semibold. SAMPLER: CLEAR SAMPLE LOCKS (S11b) — загрузка звуков из библиотеки снимает сэмпл-локи дорожки, пресет-локи остаются; по умолчанию ON. Подробно — SWIFT_MILESTONE_S9.md.
- Пианоролл (S8, новое; нижний пианоролл переименован в клавиатуру): окно на месте центра, кнопка со значком пианино на месте AUTO (тап — открыть и закрыть). Строки — только ноты гаммы, как на клавиатуре; диезы чуть другим тоном, корневая выделена; по горизонтали — выбранные страницы клипа. Справа бутерброд (GRID 1/16, 1/8, 1/4, по умолчанию 1/16; звук ноты при нажатии, по умолчанию ON — в настройках, общих для проектов) и под ним VEL. При открытии — все выбранные страницы на ширину поля. Тап по пустому — нота, по ноте — удалить; правый край — длина; сдвиг пальца по ноте — перетащить; движение пальца по пустому — прокрутка; два пальца — масштаб отдельно по горизонтали и по вертикали. У ноты своя длина и своя velocity — Level ноты (0…127, без своей — Level шага или дорожки), связанная с p-lock Level шага: p-lock — самая сильная нота шага (ноты без своей velocity получают прежний Level), p-lock Level ручкой — velocity всех нот шага; запись с VELOCITY пишет velocity нот и p-lock. Заливка velocity на нотах — всегда; VEL: проценты и вертикальный жест по ноте — только velocity; правый край ноты — длина, как без VEL. Перетаскивание ноты, единственной на шаге, переносит и шаг: p-lock и свой звук шага едут с ней (решение пользователя, S14); нота из аккорда — p-lock остаются у аккорда; через занятые шаги (аккорд, свои p-lock) p-lock проходят, не трогая их, и встают на следующий пустой шаг; отпустили на занятом — действуют p-lock того шага. Подробно — SWIFT_MILESTONE_S8.md.
- Аранжировщик (S15, решения пользователя): автоматизация — на таймлайне дорожки (окно AUTO на месте STEPS), не в паттерне; раскладка в одном масштабе (строка кнопок высотой с миниатюру, 8 строк дорожек в окне, низ — 3 строки); секции без цвета; REF — строка сверху, A/B слева от линейки, мимо мастера, в B измеритель и регулятор — референса, темп файла определяется сам; S15h — рамка в сетке, перенос клипов на ARRANGE (HERE / INSERT / TO END), ROW REPEATS, DELETE с магнитом смыкает, меню строки — двойным тапом. Подробно — SWIFT_MILESTONE_S15.md.
- Переход MIX (S10, отличия от веба): кроссфейдер ведёт всё плавно — темп, громкости, выход, мастер, RATIO, EQ мастера (в вебе Ratio, BYPASS и типы полос — на середине): BYPASS — долей глушения, разный TYPE сатуратора — через сухой сигнал на середине, полоса EQ с одной стороны — усилением или частотой к краю. Копия клипа PREV — только паттерн, без звука старой дорожки. Сетка паттернов — мультитач (несколько клипов сразу). Подробно — SWIFT_MILESTONE_S10.md.

## Вехи
S0 каркас → S1 секвенсор и экран → S2 сэмплер и редактор → S3 Plaits и свои движки, SELF-TEST → S4 FX, MOD, MORPH → S5 мастер, EQ, метры, скоп → S6 окна модулей мастера → S7 EQ Dynamic и M/S, пресеты EQ → S8 пианоролл → S9 проекты и настройки → S10 переходы между проектами (S0–S10 готовы, проверены на iPad) → S11 библиотека, импорт и экспорт, стемы, REC (готов) → S12 движки синта (готов) → S13 MIDI (готов) → **S14 оптимизация и App Store (идёт: S14e)** → S15 аранжировщик (готов) → S16 автоматизация в паттернах (нужна ли — открыто). Подробно — docs/SWIFT_AUDIT.md, раздел 6 (там же — соответствие прежним номерам).
