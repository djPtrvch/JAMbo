# Groovebox для iPad (веб-прототип)

Приложение для живых импровизационных джемов и написания треков. Референсы: Elektron Model:Samples, Drambo, Ableton Note, Remixlive, Strokes.
Устройство для теста: iPad Pro 11" (M4), Safari. Mac нет. Сначала веб-прототип, потом нативный iOS.

## Принципы
- Все ручки на экране, без глубоких меню. Не перегружать интерфейс.
- Всё привязано к сетке из 16 ручек (4 столбца × 4 ряда), чтобы позже отобразить её на 16 энкодеров (Midi Fighter Twister).
- Ручки управляются вертикальным движением пальца. Должен работать мультитач (несколько ручек одновременно).
- Стек: TypeScript + Vite, без тяжёлых фреймворков. Звук: Web Audio API (AudioWorklet при необходимости).
- Учитывать ограничения iOS Safari: аудио запускается только после касания пользователя, Web MIDI в Safari недоступен.

## Дорожки
- Базово 8, расширяемо до 16. Канал микшера первый, мастер последний.
- Свайп вниз по дорожке = mute, свайп вверх = solo (как в Drambo). Позже, при необходимости, заменим кнопками.

## Секвенсор (этап 1)
- 16 шагов, 1–4 страницы паттерна, можно укоротить длину паттерна.
- Шаг можно удлинять (как в Drambo).
- Parameter lock на каждый шаг: зажать шаг и покрутить ручку. Жёлтый индикатор на шаге = p-lock, белый = probability. На ручке жёлтым показано значение p-lock.
- Probability и Ratchet на шаг.
- Pan, Level (velocity шага) и Swing допускают p-lock.

## Сетка ручек 4×4 (этап 1)
Колонка 1 (движок, подписи зависят от типа движка):
- Сэмплер: Sample start, Sample end, Pitch, Level.
- Движки MI и wavetable: параметры по названиям из Strokes (позже), Level остаётся на 1.4.

Колонка 2: Attack, Decay, Cutoff, Resonance.
Колонка 3 (посылы FX): Reverb send, Delay send, Drive, пока пустая 4-я.
Колонка 4: Pan, Probability, Ratchet, Swing.

Типы ручек: плавная, ступенчатая (Ratchet), пустая/неактивная (подсвечивается серым).

## Режимы сетки ручек
- Выбор дорожки: ручки показывают параметры дорожки.
- Микшер: 16 ручек = громкости дорожек (не занятые дорожки не подсвечиваются).
- Мастер: сначала компрессор (Threshold, Attack, Release, Makeup; Ratio отдельной кнопкой), потом лимитер (Input, Ceiling, Lookahead, Release). Остальные колонки пока пустые.
- Удержание FX: все 4 столбца переключаются на эффекты:
  - Колонка 1 — LFO1: Wave (форма волны), Depth (глубина), Speed (скорость), 4-я пока не занята.
  - Колонка 2 — LFO2: те же параметры, что у LFO1.
  - Колонка 3 — Reverb: Size, HPF (фильтр), Level, 4-я не занята.
  - Колонка 4 — Delay: Feedback, Time, Level, 4-я не занята.
  - Пока FX удерживается, обычные параметры дорожки не меняются.

## LFO
- LFO1 и LFO2. Кнопка LFO + поворот ручки назначает LFO на параметр. Глубина задаётся теми же ручками, вокруг ручки кольцо глубины.
- Действует на выбранную дорожку, кнопка TRACK применяет на весь трек.
- Параметры самого LFO (Wave, Depth, Speed) настраиваются при удержании FX, см. выше.

## Сетка паттернов 8×8
- Столбцов столько, сколько дорожек (старт 8), рост вместе с числом дорожек.
- Переход как в Remixlive: при выборе нового проекта активные паттерны старого уходят в верхнюю строку и продолжают играть, а в сетку загружаются паттерны нового проекта.
- Каждый паттерн хранит копию звука своей дорожки.
- Запуск паттернов квантизируется.

## Пэды вместо пианоролла
- Раскладка зависит от гаммы и корневой ноты, ноты ставятся вручную, можно выбрать несколько для аккорда. Есть режим живого наигрыша (как в Drambo).

## Кнопки
PLAY, REC, PATTERNS, RANDOM (случайные шаги по гамме и корневой ноте), LFO1, LFO2, FX, TRACK (применить параметр на весь трек), UNDO. SECTION и SHIFT определим позже.

UNDO отменяет последнее сделанное действие. Реализация: история действий (стек), одно действие = один жест (например, вся протяжка ручки от касания до отпускания, одно изменение шага, одна смена паттерна). Глубина истории по умолчанию 50.

## Прочее
- Окно сэмпла: тап открывает редактор, выбор файла из папки на iPad.
- Меню «бутерброд» слева сверху: сохранение и загрузка проекта.
- Ableton Link и сайдчейн пока отложены. DJ-режим отменён (вместо него переходы между паттернами).

## План разработки
1. **Этап 1 (сейчас):** каркас экрана, сетка ручек 4×4, строка дорожек, 16-шаговый секвенсор с p-lock. Без звука.
2. Этап 2: сетка паттернов 8×8 и переключение.
3. Этап 3: звук (сэмплер, затем простые синты), микшер, посылы, мастер.
4. Этап 4: пэды, LFO, RANDOM, сохранение проектов.
5. Позже: движки MI (WebAssembly), MIDI и нативный iOS.

Правило: делать один этап за раз, небольшими коммитами. Не добавлять функции, которых нет в этом файле.
